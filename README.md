# Indian Election Analytics (1951-2024) 🇮🇳

### Project Overview
This project is a comprehensive analysis of Indian General Elections, visualizing data from 1951 to the recent 2024 elections. Built using **Power BI**, it features historical trend analysis, real-time election result simulation, and demographic insights.

### Key Features
- **Data Modeling:** Implemented a Star Schema connecting election results with Party and State dimensions.
- **Historical Analysis:** Visualized voter turnout trends and party performance over 70+ years.
- **2024 Election Center:** A real-time style dashboard showing seat shares, leading parties, and geospatial mapping of winners.
- **Advanced DAX:** Custom measures for Voter Turnout %, Seat Counting, and Dynamic Titles.

### Tools Used
- Microsoft Power BI Desktop
- Power Query (ETL)
- DAX (Data Analysis Expressions)
